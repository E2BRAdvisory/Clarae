# Impostazioni e scorciatoie

Aprite le impostazioni con `Mod+,` (o _Apri impostazioni_). Le impostazioni di editor, aspetto e scorciatoie sono **per vault** (file in `.memobrain/`); lingua e tema valgono per l'app. Se l'amministratore ha bloccato una voce, compare disabilitata con l'indicazione "gestito dall'amministratore".

| Sezione                                 | Cosa contiene                                                                                                                                                                                                      |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Generale                                | Lingua (sistema, italiano, inglese), tema (sistema, chiaro, scuro).                                                                                                                                                |
| Editor                                  | Modalità predefinita, numeri di riga, a capo, larghezza leggibile, correzione ortografica, chiusura automatica delle coppie, incolla intelligente, ripiegamento dei titoli, dimensione del carattere, tabulazione. |
| File e link                             | Formato dei link (wikilink/Markdown, percorso più breve/relativo), dove creare le nuove note, dove salvare gli allegati, cestino (sistema o vault), conferma prima di eliminare, anteprima al passaggio.           |
| Aspetto                                 | Colore d'accento, carattere e dimensione dell'interfaccia, zoom.                                                                                                                                                   |
| Scorciatoie                             | Tutti i comandi con la scorciatoia attuale: cercate, riassegnate, rimuovete; i conflitti sono segnalati.                                                                                                           |
| Note giornaliere e template             | Cartella, formato data, template.                                                                                                                                                                                  |
| Cloud · Sincronizzazione · Condivisione | Server, account, dispositivi, intervallo di polling, inviti, mount.                                                                                                                                                |
| Recupero file                           | Frequenza e limiti degli snapshot.                                                                                                                                                                                 |
| Informazioni                            | Versione, cartella dati.                                                                                                                                                                                           |

Non sono previsti plugin, temi di terze parti né CSS personalizzato: l'aspetto si regola solo con le opzioni sopra.

## Scorciatoie predefinite

(**Mod** = `Cmd` su macOS, `Ctrl` su Windows/Linux.) Tutte sono modificabili.

| Azione                         | Scorciatoia              | Azione                                | Scorciatoia                |
| ------------------------------ | ------------------------ | ------------------------------------- | -------------------------- |
| Nuova nota                     | `Mod+N`                  | Palette comandi                       | `Mod+P` / `Mod+Maiusc+P`   |
| Nuova nota in una nuova scheda | `Mod+Alt+N`              | Selettore rapido                      | `Mod+O`                    |
| Rinomina nota                  | `F2`                     | Cerca nel vault                       | `Mod+Maiusc+F`             |
| Chiudi scheda / pannello       | `Mod+W` / `Mod+Maiusc+W` | Scheda successiva / precedente        | `Mod+Alt+→` / `Mod+Alt+←`  |
| Dividi a destra / in basso     | `Mod+\` / `Mod+Maiusc+\` | Vista lettura / sorgente              | `Mod+E` / `Mod+Maiusc+E`   |
| Barra sinistra / destra        | `Mod+Maiusc+L` / `+R`    | Vista grafo                           | `Mod+Maiusc+G`             |
| Grassetto / corsivo            | `Mod+B` / `Mod+I`        | Evidenzia / barrato / codice          | `Mod+Maiusc+H` / `X` / `C` |
| Link / wikilink                | `Mod+K` / `Mod+Maiusc+K` | Elenco puntato / numerato / citazione | `Mod+Maiusc+8` / `7` / `9` |
| Attiva attività                | `Mod+Invio`              | Sincronizza ora                       | `Mod+Maiusc+S`             |
| Impostazioni                   | `Mod+,`                  |                                       |                            |

Senza scorciatoia predefinita, ma nella palette e assegnabili da _Scorciatoie_: cambio vault, passaggio chiaro/scuro, blocca/sblocca scheda e chiusure delle schede (a destra, a sinistra, altre, tutte), nuova cartella, inserisci separatore, esporta come immagine, avvio della presentazione (dall'inizio o dalla slide corrente), mostra le schede della barra destra (proprietà, link, slide, statistiche).

Nell'**albero dei file**: frecce per muoversi, `→`/`←` per espandere/chiudere, `Invio` per aprire, `F2` per rinominare, `Canc` per spostare nel cestino, tasto Menu o `Maiusc+F10` per il menu contestuale. Vedi anche [Accessibilità](accessibilita.md).
