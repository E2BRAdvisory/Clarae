# Guida utente

Nodus (nome provvisorio) è un'app per appunti e conoscenza personale che funziona **offline** su cartelle di file normali (`.md`, `.canvas`, `.base`, `.excalidraw`), compatibili con i vault di Obsidian. Il cloud è facoltativo: serve per sincronizzare più dispositivi e per condividere.

Convenzioni: **Mod** indica `Cmd` su macOS e `Ctrl` su Windows/Linux. I nomi dei comandi sono quelli della palette comandi (`Mod+P`), dove si può cercare qualsiasi azione.

> Vault privati: se perdete passphrase **e** chiave di recupero, nessuno può recuperare i dati, nemmeno l'amministratore. Leggete [Vault privati e condivisi](vault-privati-condivisi.md) prima di creare il primo.
